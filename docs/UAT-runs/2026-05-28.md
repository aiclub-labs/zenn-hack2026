### 09-11 取得手順 (Delta Detector organic 発火デモ)

本編 Step 3a で modal は出なかった (calibrated critic は hedge を 7-9 点に置くため gap rule 非発火)。この補完撮影では以下を実施し organic 発火に成功:

1. `app/api/retrieval.py` の `_embed` / `_aisearch_query` stub を実装に wire (本来 TODO で stub 返却) — citation snippet が AOAI prompt に渡るように
2. AI Search index `corpus-dev` に表面処理 record (`uat-seed-surface-treatment`, sf_surface_treatment, w=0.8) を seed
3. `scripts/reset_tenant.py --sector manufacturing-s8b --unit line-A` で前 UAT の `delta_events` cooldown を全削除 (7 日 cooldown が阻害していた)
4. /chat で挨拶 prompt → banner ack → recall prompt 「ライン A で 5/22 に発生したクラックで、自分はどう判断した?」を投入
5. Delta Detector が `defect_root_cause` schema_field に対し hard gap 検出 (`self_critic=0.0` from user-turn) → HearoutAgent kick → modal 自動表示

設計の意図通り。「captured citation あり + recall hedge」は 8.0 点で発火せず、純粋 recall (citation 範囲外) は発火する、という gap_rule の境界が画像で確認できる。
